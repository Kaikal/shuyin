FAQ

常见问题

疏音提供音乐内容吗？

不提供。疏音本身不含任何音频文件，也不内置任何音源。你听到的内容，一部分是你设备上本来就有的文件， 另一部分是在对应平台用你自己的账号获取的。会员权益、可播范围都以各平台的服务条款为准。

不上架应用商店，怎么安装？

安卓端下载 APK 后直接安装即可，系统可能会提示「未知来源应用」，在安装界面允许一次即可。 Windows 端下载的是 Tauri 打包的安装程序，体积比 Electron 方案小很多，也不需要额外装运行库。

我的数据会被上传吗？

不会。曲库索引、播放记录、收藏都只存在本机。云同步是可选项，而且用的是你自己的云环境—— 数据在你自己的账号下，疏音没有中转服务器。

电脑和手机之间怎么同步？

两种方式：导出配置包（U 盘、微信传文件都行），或者登录你自己的云环境后一键同步。 同步的内容是歌单、收藏、主题、音效参数和快捷键，不包括音频文件本身。

为什么桌面版版本号比安卓低？

两个端的历史版本线不同。最近一轮改动（平板大屏排版、五段均衡器、切后台不停播）先落在安卓上， 桌面端正在对齐，版本号会在下一次发版时接上。
